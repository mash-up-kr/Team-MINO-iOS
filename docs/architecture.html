Team-MINO-iOS Architecture

Clean Architecture + DDD · MVI + Coordinator + DI · 레이어 단위 로컬 SPM 패키지

레이어 규칙

  • • 의존은 바깥 → 안쪽으로만. Domain 은 바깥 레이어를 모른다
  • • DTO 는 Data 내부에 닫히고 toDomain() 으로만 경계를 넘는다
  • • Entity 는 Codable 직접 채택 금지 (API 스키마 결합 방지)
  • • reduce 는 Repository 가 아니라 UseCase 를 받는다

화면 아키텍처 — MVI + Coordinator + DI

  • • 순수 reduce 가 부수효과를 Effect 값으로 반환, 실행은 Store 가
  • • 화면 전환은 Effect.navigate → Coordinator 가 전담
  • • 자식 flow 종료는 FlowFinish 로 결과를 1회 보고
  • • Coordinator 별 좁은 deps 프로토콜 + 생성자 주입 (전역 컨테이너 0)

라이브러리

  • • 외부 라이브러리 없이 애플 프레임워크만 사용 (No 서드파티)
  • • Combine 대신 async/await 기반 스트림 사용
  • • Store는 Observation만 의존 (SwiftUI 비의존)
  • • App.xcodeproj는 xcodegen 1회 부트스트랩 산출물
